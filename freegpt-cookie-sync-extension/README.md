# FreeGPT Session Sync Extension

A lightweight Chrome/Edge browser extension to extract your active ChatGPT session credentials into `chatgpt-auth.json` in one click.

## How to Install

1. Open Chrome or Edge and navigate to `chrome://extensions`.
2. Enable **Developer mode** in the top right corner.
3. Click **Load unpacked**.
4. Select this directory (`freegpt-cookie-sync-extension`).
5. Open [chatgpt.com](https://chatgpt.com) and ensure you are logged in.
6. Click the **FreeGPT Session Sync** icon in your browser toolbar.
7. Click **Export chatgpt-auth.json**.
8. Move the downloaded `chatgpt-auth.json` into your FreeGPT folder or configure `"cookie_file": "chatgpt-auth.json"` in `config.json`!
